## 1. Tecnología: A-Frame
| Característica | Descripción |
|----------------|-------------|
| Entorno 360° | Visualización de un entorno de despliegue lógico de software. |
| Modelo 3D | Representación visual de un Nodo/Servidor de aplicaciones. |
| Interactividad | Eventos de usuario para inspección de procesos y servicios. |
| VR | WebXR para navegación inmersiva por el stack de servicios. |

---

## 2. Las 3 Escenas
| Escena | Tipo | Contenido |
|--------|------|---------|
| 1 | 360° | Dashboard de monitoreo de red (Panel de control del sistema). |
| 2 | 3D | Visualización del nodo de servicios (Servidor de aplicaciones). |
| 3 | 3D | Diagnóstico de servicios, procesos activos y estado de la app. |

---

## 3. Criterios de Evaluación
| Criterio | Software | Documentación |
|----------|----------|---------------|
| **a) THD** | Escena 360° + Nodo 3D | Especificación de procesos y servicios |
| **b) Producto** | Interfaz de diagnóstico interactiva | Log de estados del software |
| **c) Sostenibilidad** | Optimización de assets web | Eficiencia del stack tecnológico |
| **d) Mercados** | Gestión de servicios en la nube (Cloud) | Análisis de mercado de Software |
| **e) Negocio** | Reducción de tiempo en despliegue (TTR) | ROI del monitoreo visual |
| **f) IT + OT** | Gestión de sistemas y despliegue lógico | Convergencia de gestión de software |
| **g) Informe** | — | Este README.md |

---

## 4. Sostenibilidad (Criterio c)
- **Eficiencia del Stack:** Optimización de la carga de modelos 3D y scripts para reducir la latencia de red y el consumo de ancho de banda.
- **Impacto:** Digitalización de los procesos de auditoría de servicios, eliminando la necesidad de inspecciones manuales en consolas remotas de alto consumo.
- **Optimización de recursos:** Implementación de carga diferida (lazy loading) de componentes para reducir el uso de CPU/RAM en el equipo del usuario.

---

## 5. Capturas de Interfaz
* **Entorno 360°:** Mapa lógico de la red y servicios activos.
* **Nodo 3D:** Representación gráfica del servidor donde se alojan las aplicaciones.
* **Panel de Diagnóstico:** Interfaz de usuario para consultar procesos, logs y estados de salud del servicio (Health Check).

---

## 6. Uso
1. **Acceso:** Abrir el despliegue en GitHub Pages.
2. **Navegación:** Explorar el entorno de servicios de software mediante el cursor.
3. **Interacción:** Hacer clic sobre el nodo para acceder al **panel de diagnóstico de procesos**.
4. **Modo VR:** Activar WebXR para una visualización inmersiva del stack de servicios.
